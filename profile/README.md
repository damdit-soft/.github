# Damdit

**AI builds the website. Damdit checks it.**

Damdit audits a website the way a visitor's browser sees it. It renders the pages, checks them against fixed rules for SEO, accessibility, performance, security and AI readiness, and shows the evidence behind every issue: the page, the element and what was measured. It also says what it could not check, and the next audit shows what is resolved, what is new and what came back.

It comes in two forms with one licence:

- **[Damdit for Mac](https://damdit.com/download/)**: the app, for Apple silicon.
- **[Damdit CLI](https://damdit.com/cli/)**: the same Full Audit as a command, in Docker on a Mac, Linux or a server, in a pipeline, or as a tool your AI agent calls over MCP.

```sh
curl -fsSL https://download.damdit.com/cli/install.sh | sh
```

Damdit is closed source. This organisation is where we work in public:

- **[damdit-public](https://github.com/damdit-soft/damdit-public)**: bug reports, feature requests, the roadmap and release notes.
- **[damdit/damdit](https://hub.docker.com/r/damdit/damdit)** on Docker Hub: the Damdit CLI image.
