# Damdit

**AI builds the website. Damdit checks it.**

Damdit is a website audit app for Mac. It opens your pages in a real browser, checks them against fixed rules and shows the evidence behind every issue: the page, the element and what was measured. It also tells you what it couldn't check, and the next audit shows what is resolved, what is new and what came back.

The app is closed source. This organisation is where we work in public:

- **[damdit-public](https://github.com/damdit/damdit-public)**: bug reports, feature requests, the roadmap and release notes.

## Talk to us

- Something looks wrong: [report a bug](https://github.com/damdit/damdit-public/issues/new?template=bug.yml). In the app, **Settings → About & Support → Report a Bug…** fills in your version and system.
- An idea: [request a feature](https://github.com/damdit/damdit-public/issues/new?template=feature.yml).
- Account, licence or payment: support@damdit.com
- A security issue: please report it privately, see the [security policy](https://github.com/damdit/damdit-public/security/policy).
